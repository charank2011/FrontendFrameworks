My Responsive Web Page

Welcome!

This is a sample web page created to demonstrate responsiveness and Git version control exploration. The layout is designed to adapt to various screen sizes, providing an optimal viewing experience on both desktop and mobile devices.

The goal of this exercise is to ensure the webpage displays well on different devices while maintaining proper version control documentation.

Key Features

  • Responsive layout using CSS media queries.
  • External CSS file for clean separation of content and style.
  • Git version control for tracking changes.
